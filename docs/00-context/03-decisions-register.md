# LearningHub - Registre public des décisions candidates

> **Baseline publique candidate.** Cette page est un document de cadrage. Elle ne prouve ni implémentation, ni validation métier, ni approbation de mise en production.

Ce registre sépare **orientation retenue pour écrire une proposition** et **décision d'architecture officiellement approuvée**.

| ID | Orientation documentée | État | Preuve manquante |
|---|---|---|---|
| `LH-DEC-001` | LearningHub est maître du résultat pédagogique | PROPOSED | Revue domaine |
| `LH-DEC-002` | Commencer par un R1 gratuit autonome | PROPOSED | Validation produit R1 |
| `LH-DEC-003` | Version de cours immuable après publication | PROPOSED | ADR + scénarios de correction |
| `LH-DEC-004` | Accès calculé à partir d'un AccessGrant explicite | PROPOSED | Matrice de permissions |
| `LH-DEC-005` | Intégrations CommerceHub et ProjectHub hors R1 | PROPOSED | Contrats inter-systèmes |
| `LH-DEC-006` | Architecture modulaire Django / DRF / PostgreSQL / Next.js | PROPOSED | ADR technique |
| `LH-DEC-007` | Événements fiables via outbox pour processus inter-contextes | PROPOSED | POC et vérification |
| `LH-DEC-008` | Pas de publication automatique des sources privées | Politique publique proposée | Revue mainteneur |

La fusion de cette page ne change pas ces statuts. Consulter le [registre ADR](../07-architecture/05-adr-register.md).
